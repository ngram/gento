# 利用にあたっての注意

**この gem を使って何を取得し、それをどう使うかの適法性は、利用者自身が判断・確認してください。**

gento は URL を渡すとページ画像の URL を返すだけの道具です。
対象サービスの利用規約、`robots.txt`、著作権法その他の関係法令に照らして、
その利用が許されるかどうかは、**利用者の目的・態様・地域によって変わります。**
リポジトリおよび gem の提供者は、その判断を代行しません。

特に次の点は、使う前にご自身で確認してください。

- 取得対象サービスの**利用規約**（スクレイピング・自動アクセス・再配布の可否）
- 対象サービスの **`robots.txt`** とレート制限
- スライドそのものの**著作権**、および取得した画像の利用方法
- 業務利用・商用利用の場合は、必要に応じて**法務・専門家への確認**

## この gem 側での設計

判断の材料として、この gem がしていること／していないことを挙げておきます。
これは適法性を保証するものではありません。

- 画像を**再ホストしません**。各サービスのオリジナル URL を返すだけです。
- **認証を回避しません**。公開されているページのみを対象にします。
- SlideShare のボット判定を**突破しません**。検出した時点でエラーを返して止まります。
- 取得先の **`robots.txt` を既定で参照し、拒否されているパスは取りに行きません**
  （[docs/robots.md](robots.md)）。無効化する手段はありますが、その判断は利用者のものです。
- 1 回の `fetch` で送るリクエストは数件です。並列実行やリトライの方針は利用者側の実装に委ねます。
